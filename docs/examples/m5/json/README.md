# Образцы JSON balance v1

Это примеры [контракта ADR-0020](../../../decisions/ADR-0020-ranged-balance-json-v1.md). **Schema, parser и result encoder реализованы**; application service/error encoder/CLI balance ещё впереди. Файлы balance не принимаются `towr simulate`, а команды `towr balance` пока нет. Рабочий запуск тех же входных данных доступен через [Python-пример](../README.md).

- [balance-v1.request.json](balance-v1.request.json) — полный резерв P1/P2 против A1/A2/B1, отдельные family facts, группы A=0..2/B=0..1, окно [1/4,3/4] с target 1/2, seed 42, stages 8/keep 3 и 32/keep 2. C=5, верхний бюджет 136. Outer request_id и reserve.initial_request_id имеют разные значения.
- [balance-v1.result.json](balance-v1.result.json) — проекция **реального** existing generation/staged result на предложенный wire формат, с полным echoed request, каталогом составов и всеми aggregate reports. Runtime: CPython 3.14.5, random.Random; sequential и process (workers=2, batch_size=4) дали равные typed results.
- [balance-v1.input-error.json](balance-v1.input-error.json) — иллюстрация ответа при замене minimum.denominator на 0. Сам сохранённый request корректен.
- [balance-v1.generation-error.json](balance-v1.generation-error.json) — иллюстрация сбоя materialization состава (1,0) после preflight; без этапа/partial output.
- [balance-v1.execution-error.json](balance-v1.execution-error.json) — иллюстрация сбоя кандидата (1,1) на этапе с индексом 1; без counts/partial reports.

Error envelopes написаны как примеры будущего формата, а не получены от ещё отсутствующего error encoder. Текст message не является стабильным API. Нет wire-документа для I/O failure: stderr и exit 4 определены отдельно в ADR.

Положительный пример подготовлен одноразовым mapping probe: build_request существующего Python-примера → M4 scenario encoding → strict M4 admission/обратное отображение → public RangedCompositionGroup/ObjectiveRateWindow/RangedCandidateGenerationRequest → generate_ranged_candidates → evaluate_ranged_candidates_staged. Временный probe использовал внутреннюю M4 request projection только для извлечения scenario; это не новый public API и не предлагаемая реализация balance parser. Восстановленный typed request точно равен исходному. Обе оценки исполнены в реальных sequential/spawn процессах; результат сериализован без изменения наблюдений. Реализованные adapters воспроизводят это отображение непосредственно по ADR; saved aggregate JSON проверяется на explicit typed fixtures без фиксации случайного результата будущих прогонов.

Наблюдения первого этапа для (0,1)/(1,0)/(1,1)/(2,0)/(2,1) дают objective counts 8/8/2/2/0 из 8. В уточнение проходят (0,1), (1,1), (2,0): промежуточный outside-window кандидат допустим. На втором этапе objective counts 31/13/13 из 32; final selection — (1,1), (2,0). Это иллюстрация seed/runtime, не обещание вероятности и не фиксированное ожидание статистического теста. Последний continuation пуст, поскольку третьего этапа нет.

Для process-входа заменяется только execution на `{"mode":"process","workers":2,"batch_size":4}`. Сравниваются aggregates/selection, а не весь JSON с отличающимся echoed execution. [Матрица проверок](../../../decisions/ADR-0020-ranged-balance-json-v1.md#матрица-проверки-и-порядок-реализации) отдельно покрывает Schema/adapters, early stop, unsupported observations и ошибки. Первоначальный mapping probe дополнен 22 unit и 2 integration tests готовых Schema/adapters. CLI и error encoder пока не проверяются: они ещё не реализованы.

Готовые Python entry points: [parse_ranged_balance_request / encode_ranged_balance_result](../../../../src/towr/adapters/ranged_balance_json.py), [RangedBalanceCommand / RangedBalanceResult](../../../../src/towr/application/ranged_balance_models.py). Parser принимает str или UTF-8 bytes. Caller явно вызывает существующие generate_ranged_candidates и evaluate_ranged_candidates_staged с command.execution, объединяет их результаты в RangedBalanceResult и передаёт encoder вместе с исходной command. Для process нужен importable guarded main, как в существующем Python-примере. [Integration tests](../../../../tests/integration/test_m5_ranged_balance_json.py) показывают эту цепочку для обоих режимов. Error examples уже проходят error Schema, но остаются иллюстрациями до реализации encoder.
