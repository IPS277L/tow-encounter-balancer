## Полевая матрица fresh scenario

Префикс `S` означает `/scenario` для simulation и `/reserve/scenario` для balance. [Simulation request Schema](../../src/towr/adapters/schemas/magic-simulation-request-v1.schema.json) описывает общую форму; mapper вызывает существующие public constructors. Все поля обязательны, nested objects закрыты, nullable values и пустые arrays явные. Каждый array order сохраняется независимо; ID не trim/coerce.

## Ограничения и итог

- Только fresh authored Champion-Wizard/Curse и numeric Shooting Minions в замкнутой сцене. Нет full NPC/spell/Talent/item каталогов, PC, универсальной тактики, auto facts/backend, произвольной загрузки текущего боя или расширения gameplay scope.
- Curse/Broken Recover/Run и Stomach Blow→Drained expiry готовы; прочие mandatory Wound/Miscast/chronology, ordinary Attack Give Ground, unknown frame/route дают exact unsupported stops. Эти observations сохраняются в N, не становятся defeat/draw и не отфильтровываются как «неудобные» результаты.
- Не все reachable future frames обязательны; unknown route не исправляется. Недопустимая projection прерывает family целиком. Нет nearest fallback, confidence/difficulty presets или гарантии истинной вероятности при eligible/window_match.
- Каждый stage оплачивает полный rerun от index0; observations разных stages не независимы. Нет prefix reuse/cache/persistent pool.
- Aggregate-only output не является streaming: runners создают records, generator — family, encoder — полный JSON. Caps не wall-time/RSS limits; cleanup ждёт running work, rollback/мгновенный kill не обещаются. Получатель должен сохранять exact большие integers и отбрасывать partial bytes при I/O failure.
- Source equality структурная, не криптографическая. Manual aggregates и runtime metadata не доказывают происхождение наблюдений. Process callers требуют importable main guard.
- Среда только **CPython3.12.15/macOS arm64**. Другие Python/ОС/RSS и новые performance-замеры не проверены.

Последняя полная регрессия того же byte-identical src/tests/tools: **3424 tests /33 прежних errors (158,007с)**, все138implementation tests и probe — OK. Counters полных error headers/subtests и exception signatures равны предыдущим3383tests; новых ошибок нет.
