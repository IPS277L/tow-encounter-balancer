# ADR-0001: границы моделей первого среза

Статус: принято, 2026-08-18.

## Контекст

Один шаблон бойца должен безопасно использоваться в тысячах симуляций. Атаки могут использовать базовую характеристику или собственный бросок. Будущие правила потребуют журналирования и точек расширения, но полный плагинный движок пока не нужен.

## Решение

- Разделить `CombatantDefinition` и `CombatantState`.
- Представлять источник броска объединением `StatRollSource | InlineRollSource`.
- Внедрять RNG через протокол.
- Использовать явный конвейер разрешения атаки и наблюдаемые структурированные события.
- Не реализовывать универсальную event bus до появления конкретного изменяющего события правила.

## Последствия

Симуляции получают чистое начальное состояние и воспроизводимы. Будущие виды атак не требуют изменения модели бойца. При добавлении реакций потребуется спроектировать типизированные перехватчики, не ломая формат наблюдаемых событий.
