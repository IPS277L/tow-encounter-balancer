# ADR-0131: ускоренный шаг численности на крайнем плато

Дата: 2026-11-17. Статус: эксперимент отклонён по заранее заданным gates. Рабочий код ADR-0128 восстановлен побайтно по точному snapshot.

## Основание и одна изменяемая величина

[Контроль устойчивости](../benchmarks/dynamic-stability-2026-11-17.md) нашёл full UI mixed-magic202:434победы игроков,2unknown,0поражений; посещён максимум8NPC при разрешённых10. Все допустимые screening дали100%побед. Существующий ADR-0128 увеличивает число на1только в части адаптивных ветвей и может долго оставаться в лёгкой области.

В **уже существующей** count-change ветви после выбора прежнего parent вычисляется step. Если непустой набор всех наблюдений без unsupported имеет одинаковые крайние win rates1либо0, step=(distance_to_bound+1)//2; иначе step=1. Рост добавляет stepновых sample NPC к существующим; уменьшение выполняет stepпоследовательных random pop из текущей длины. Старые NPC и относительный порядок оставшихся сохраняются. Значения1/0 — результат измерений, не утверждение о монотонной трудности.

Parent,30%random restarts, расписание count/component branches, final win→rounds score, C/E/V, seeds, kernel и JSON не меняются. Уже достигнутый target, границы, fixed count/C1 сохраняют прежний путь. Step1 делает прежние RNG вызовы; никакого нового RNG для выбора step нет. После неоднородных оценок используется прежний ADR-0128. Unsupported остаётся в отчётах и исключается из plateau-сигнала/рекомендаций по прежним правилам.

## Критерии до candidate измерений

1. Детерминированные проверки growth/shrink/clamp, пустого eligible/unknown, некрайних/разных win rates, target/bounds. Source/budget/progress/cancel/independent validation сохраняются; fixed-count/C1 сравнить полным текущим JSON result с reference.
2. Шесть исходных112-trial inputs42/202 из контроля устойчивости, неизменные process4/source и budget. В двух застрявших202cases (melee/mixed-magic) validation win rate должна стать<1и ближе50%; macro mean win error6строк — ниже reference. В остальных4cases допустим рост win error не более1/32 (одна победа validation); это прагматический go/no-go, не статистический тест. **Всего unsupported по каждому короткому поиску не больше reference0**, без proposal cap/новой execution error. Показываются все пары, duration и фактическое время; более тяжёлые бои могут стоить дороже.
3. До правки снять дополнительный reference mixed303/112, затем после прохождения п.2 повторить candidate на том же входе: recommendation обязательна, win error не хуже reference, unsupported не больше, proposal cap не возникает. Seed303 выбран заранее; формулу/gates после его результатов не подбирать.
4. Только после п.2–3 — полный UI mixed-magic202/436против сохранённого reference100%побед. Для внедрения нужна поддержанная рекомендация с point win error≤10п.п., сохранение guards и search+encoding≤900s на измеряемой машине. Новых причин unsupported быть не должно; известные GM/spatial stops видимы, их общее число и исключённые составы обязательно показать. Duration — вторичный показатель принятого score, его возможное ухудшение не скрывать. Один успешный full seed не доказывает общего превосходства.

При невыполнении gate экспериментальная правка не внедряется: вернуть только собственный точный snapshot, не затрагивая прежние незакоммиченные изменения. Raw results/решение сохранить. Нужные адресные проверки — по влиянию; full regression/wheel ради эвристики не нужны. Не менять одновременно score, allocation, fallback или game rules и не возвращать uniform anchors ADR-0127.

## Результат

На шести112-trial inputs выполнены672candidate trials. Melee202улучшился100→75%, но mixed-magic202остался100%. Mixed-magic42ухудшился71.875→93.75%: рост win error21.875п.п. против допуска3.125. Macro error слегка снизился25.521→25.000п.п., что не отменяет оба нарушенных gates. Unsupported0/proposal cap0, но условий внедрения это не заменяет. Candidate303и full UI202не запускались; заранее снятый303reference сохранён, формула/критерии не подбирались.

Helper/циклы и экспериментальные tests архивированы в `.cache/adr131/`, затем удалены из рабочего исполнения. Точные прежние source bytes и source SHA-256 восстановлены; остальные ранее авторизованные изменения не затронуты. Адресная проверка восстановленного алгоритма/current JSON/progress —46OK/31.702s. Wheel/full regression не запускались. [Все пары, стоимость и разбор двух10NPC](../benchmarks/dynamic-plateau-escape-2026-11-17.md).

Быстрый выход к верхней численности не равен поиску подходящей силы: в регрессировавшем42кандидат достиг10NPC, но состав имел другие характеристики/снаряжение и сохранил6первых NPC. Следующий шаг — повторная оценка двух фиксированных составов на новом заранее выбранном seed, прежде чем вводить component-level адаптацию или менять формулу шага.
