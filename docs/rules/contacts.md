# Контакты

Источники: `BOOK-PLAYER-GUIDE`, версия 1.4, глава Character Creation — Contacts, страницы 56–60; `BOOK-GM-GUIDE`, версия 1.1, глава Contacts, страницы 19–41. Статус области: `draft`; правила извлечены, но campaign/downtime layer ещё не реализован.

## RULE-CONTACT-001 — стартовые Contacts

Персонаж начинает с двумя конкретными NPC Contacts. Для каждого выполняется отдельный бросок по одной из двух Contact Tables, указанных в Career: можно бросить один раз по каждой таблице или дважды по одной. Дублирующийся результат перебрасывается.

С согласия GM один результат можно заменить выбранным Contact. Случайное определение Contacts не даёт XP.

Источник: страница 56.

## RULE-CONTACT-002 — таблицы Talagaad

Для кампании в Talagaad книга предоставляет четыре группы Contacts: The Great and the Good, Comrades in Arms, The Common Folk, Wanderers and Wastrels. В каждой группе `d100` сначала определяет одного из пяти NPC диапазоном в 20 значений, а поддиапазон в 5 значений определяет характер отношений.

Источник: страницы 57–60. Имена NPC, Archetypes и варианты отношений являются данными кампании, а не ветвлениями resolution kernel.

## RULE-CONTACT-003 — структура Contact

Каждый Contact имеет Archetype и Primary Skill. Gamemaster’s Guide предоставляет по одному готовому Contact для каждого из 20 Archetypes и рекомендует при переносе кампании в другое место создать или адаптировать по одному NPC каждого Archetype. Конкретного NPC разрешено определить во время игры совместно с игроками.

Готовые Contacts Talagaad используют указанный в книге Suggested NPC profile с нужными изменениями; книга отдельно уточняет, что все они считаются Champions. Это описание NPC и его боевого состояния, а не дополнительный бонус Contact.

Источник: Gamemaster’s Guide 1.1, страницы 19–20.

## RULE-CONTACT-004 — Primary Skill помогает в Endeavour

Если Endeavour требует Test того же Skill, который является Primary Skill одного из Contacts персонажа, персонаж получает `+1d`. Несколько Contacts с одинаковым Primary Skill не складываются: итоговый бонус всё равно равен `+1d`.

Это узкий downtime modifier. Contact не выполняет приключение вместо персонажа и не гарантирует помощь вне Endeavour. Крупная услуга может создать долг, быть оплачена встречной услугой через Aid Contact Endeavour или быть отклонена до погашения прежних долгов; конкретное решение остаётся за GM.

Источник: Gamemaster’s Guide 1.1, страница 21.

## RULE-CONTACT-005 — превращение NPC в Contact

Знакомого NPC можно сделать новым Contact через Aid Contact Endeavour, если GM согласен, что описанный способ развития отношений подходит. Для NPC выбирается уместный Primary Skill; персонаж выполняет соответствующий обычному Endeavour Test как Exacting Test:

- требуется суммарно `4` успеха;
- разрешён один бросок за каждый Endeavour;
- новый Contact не обязан соответствовать одному из 20 исходных Archetypes.

Источник: Gamemaster’s Guide 1.1, страница 21.

## Граница нормативности

Объяснение в Player’s Guide на странице 56, что Contact служит первым источником сведений или совета, задаёт роль системы, но не гарантирует автоматический успех и не определяет стоимость помощи. Описания четырёх групп на страницах 57–60 и поля Favours/Needs на страницах 22–41 Gamemaster’s Guide характеризуют возможные ресурсы, сюжетные долги и зацепки. Они классифицированы как `GUIDANCE`, а не как фиксированный прайс-лист, автоматический успех или исполняемая Ability. Универсальная числовая механика этих профилей — только бонус Primary Skill из `RULE-CONTACT-004`.
