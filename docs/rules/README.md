# Нормализованные правила книги

Здесь размещаются правила, извлечённые из главного rulebook. Один документ должен описывать связную область механики, а не повторять структуру книги механически.

Каждое правило получает идентификатор и ссылку на книгу, главу и страницу. Черновой текст не считается утверждённым, пока не проверен в контексте соседних разделов и не получил статус `approved`.

Предполагаемые области будут создаваться по мере фактического анализа: базовые проверки, бой, действия, состояния, персонажи, магия, снаряжение и другие обнаруженные системы.
