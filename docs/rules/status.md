# Status

Источник: `BOOK-PLAYER-GUIDE`, версия 1.4, глава Abilities — Status, страница 89. Статус области: `draft`; affordability и social modifiers требуют страниц 90–105 и 129–130.

## RULE-STATUS-001 — три уровня

Status имеет три tier: `Brass`, `Silver`, `Gold`. Career задаёт Status игрового персонажа; изменить его можно через Change Career Endeavour.

Status определяет:

- доступный уровень расходов;
- ожидания NPC в Social Encounters;
- уместность trappings, Assets и establishments относительно общественного положения.

Источник: страница 89. Описания быта трёх tier являются setting guidance; они не задают автоматические наказания, кражу или конфискацию без отдельного решения GM/сценария.

## RULE-STATUS-002 — зависимые правила

Снижение Status через Life in Disgrace, бросок Random Asset Table «на ступень выше» и временная маскировка Quick Change используют порядок `Brass < Silver < Gold`. Однако точная affordability и bonus/penalty social Tests окончательно определяются профильными разделами, а не выводятся из художественных описаний страницы 89.
