# Исторические инструменты приёмки

По [ADR-0063](../../docs/decisions/ADR-0063-single-current-magic-contract.md) удалены исполняемые матрицы старых Magic JSON-контрактов:

- `tools/audit_m8_transport_install.py` — аудит версий1–4;
- `tools/audit_m8_magic_v5_installed.py` — аудит версии5.

Их исходники и соответствующие фактические результаты доступны в Git до ADR-0063. Они не являются текущими командами приёмки. Исторические ссылки отчётов ведут сюда, чтобы не требовать исполняемой поддержки старых форматов.

Текущая проверка Magic выполняется адресными schema/JSON/CLI tests и public examples6. `tools/prepare_m8_transport_audit.ps1` остаётся средством сборки и установки пакета для обоснованной контрольной точки; при изменении конкретного механизма доставки проверяется соответствующая установленная граница по [политике проверок](../../AGENTS.md#политика-проверок).
